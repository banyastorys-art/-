## 📂 Use Case Showcase 페이지 디자인 시안: '시간 절약 증명 아카이브'

### 💡 목표 및 컨셉 개요
*   **페이지 목적:** 사용자가 AURA Pro를 구매함으로써 얻게 되는 명확한 **ROI(Return On Investment)**와 **시간적 이득(Time Saving)**을 감성적으로 설득하는 것.
*   **전략:** '문제 제기 (Pain Point)' $\rightarrow$ 'AURA의 개입 (Solution Hook)' $\rightarrow$ '결과 증명 (Proof & CTA)'의 3단계 구조를 따릅니다.
*   **브랜드 톤 반영:** 모던 오가닉, 전문적이고 직관적인 시각 경험 제공.

### 💻 와이어프레임 및 인터랙션 상세 설계

#### 1. 히어로 섹션 (The Hook: Pain Point 제시)
(스크롤 시작점)
*   **헤드라인:** "시간이 돈입니다. AURA는 당신의 시간을 되찾아 드립니다."
*   **서브 카피:** 수많은 정보를 조합하고, 분석하며, 시각화하는 과정에 낭비되는 모든 시간과 에너지를 AI가 단번에 정리합니다.
*   **핵심 비주얼 요소 (Interactive):** **[시간 비교 슬라이더]**
    *   사용자가 좌우 슬라이더를 움직일 때마다 배경의 예시 결과물이 '수작업 방식'에서 'AURA Pro 방식'으로 즉각 변환됩니다.
    *   *Before Side (좌측, 기본/Free):* 복잡하고 산만한 수동 데이터 그래프와 텍스트가 나열됨. (느낌: 혼란스러움)
    *   *After Side (우측, Pro):* 깔끔하게 구조화된 '안티그래비티 노드' 기반의 완성도 높은 컬러 팔레트/레이아웃 시안이 나타남. (느낌: 명확함)

#### 2. 메인 섹션 1: 스토리텔링 케이스 스터디 (The Value Proof)
*   **섹션 제목:** [케이스 A] "3일 만에 끝나던 브랜딩 프로젝트, 단 30분으로 압축."
*   **구성:** 수평적인 3단계 타임라인(Timeline) 구조를 활용합니다.

| 단계 | 내용 (와이어프레임 요소) | 인터랙션/로직 | 강조할 Pro 가치 |
| :--- | :--- | :--- | :--- |
| **STEP 1: 문제 정의** | [Free 사용 시] - 수많은 영감 이미지들을 모으는 작업 과정을 보여주는 그리드. (어떤 조합이 좋을지 판단하기 어려움).<br>**텍스트:** "수백 개의 레퍼런스 속에서 핵심 메시지를 찾기란..." | 사용자에게 '분산된' 이미지를 느끼게 함. | *N/A* (고객의 고통) |
| **STEP 2: AURA Pro 작동** | [Pro 사용 시] - 사용자가 원하는 키워드(예: Minimal, Organic, High-end)를 입력하는 필드와 함께, 'AI 분석 시작' 버튼. 이 버튼을 누르면 로딩 애니메이션과 함께 '필터링/구조화 과정'이 시각적으로 진행됨. | **핵심:** 사용자가 Pro 기능을 사용하는 순간의 *쾌감*을 느낄 수 있도록 간결하고 빠른 인터페이스로 구현. (Loading Animation에 시간 절약 메시지 삽입) | **Advanced Pattern Recognition** (전문적인 패턴 인식 기능 - Pro 전용). |
| **STEP 3: 결과 도출 & ROI 증명** | [결과 아웃풋] - AURA가 최종적으로 제시한 '구조화된 컬러 시스템'과 '최적의 레이아웃 제안'. 이 시안에 명확하게 **[Pro Utility Badge]**를 붙여야 함. <br>**수치 강조:** "💡 3일간의 리서치 시간을 단 **25분**으로 압축했습니다." | Pro 기능이 도출한 결과물에 마우스 오버 시, 해당 기능의 상세 설명(예: '시장 트렌드 연동 알고리즘')과 함께 작은 애니메이션 효과를 준다. | **구조적 가이드 제공 (Systematic Output)** (가장 높은 가치). |

#### 3. 메인 섹션 2: 핵심 비교 테이블 보강 (The Final Push)
*   **제목:** "Pro 버전은 단순한 기능 추가가 아닙니다. '업무 방식 자체의 업그레이드'입니다."
*   **구성:** 기존 Free/Pro 비교 테이블을 유지하되, **[Benefit Column]**을 추가합니다.

| 기능 (Feature) | Free Plan | Pro Plan (Locked Icon) | 💰 이 비용이 나에게 주는 가치 (Benefit) |
| :--- | :--- | :--- | :--- |
| 기본 컬러 조합 생성 | ✅ 제한적 사용 가능 | **✅ 무제한 / 고급 알고리즘** | "막연함 제로. 전문가 레벨의 색상 팔레트 확신." |
| 시간 절약 리포팅 | ❌ 불가 (수동 계산) | **✅ 자동 보고서 생성** | "**시간 확보.** 주간/월간 마케팅 보고서 작성이 몇 시간이 단축되는지 즉시 확인하세요." |
| 전용 패턴 인식 노드 | 🟡 기본 노드만 제공 | **💎 안티그래비티 고급 노드 (Pro)** | "**퀄리티 극대화.** 단순 디자인을 넘어, 예술적 깊이와 구조를 확보합니다." |

### 🛠️ 코다리에게 전달할 개발 가이드라인 요약
1.  **최우선 구현 목표:** 섹션 1의 **시간 비교 슬라이더(Interactive Time Comparison Slider)** 로직 구축 및 애니메이션 최적화.
2.  **상태 관리 (State Management):** Free/Pro 토글 상태가 바뀌면, 단순 UI 변경을 넘어 배경 이미지와 수치 데이터($3일 $\rightarrow$ 30분)까지 동기적으로 변화하는 로직 구현 필수.
3.  **CTA 배치:** 페이지 하단에 '지금 Pro로 전환하고 시간을 되찾으세요'라는 문구와 함께 PayPal 결제 CTA를 재배치하여 구매 흐름을 완성합니다.
