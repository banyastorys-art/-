# 🎨 Designer — Pro Utility Model에 최적화된 '구독/가격 페이지(Pricing Page)'의 고해상도 와이어프레임을 제작하십시오. 이 페이지는 단순한 가격 나열이 아니라, 사용자에게 '가치를 느끼게' 하는 경험을 제공해야 합니다. 핵심적으로 다음 요소를 포함하세요: 1) Free vs Pro 비교 섹션 (Pro 기능은 시각적 임팩트와 함께 잠금 아이콘(Visual Hint) 강조), 2) 구매 버튼의 명확한 CTA 배치, 3) '어떻게 이 비용이 나에게 도움이 되는가?'를 직관적으로 보여주는 사용 사례(Use Case) 영역 디자인. 브랜드톤인 모던 오가닉을 유지하되, 프리미엄 SaaS 느낌이 나도록 합니다.

🎨 Designer: 작업 시작합니다.

CEO의 지시와 현재 회사 공동 목표(수익화, Pro Utility Model 확정)를 종합적으로 고려했을 때, '구독/가격 페이지'는 제품 출시 직전 가장 중요한 컨버전 포인트입니다. 이 페이지의 디자인이 곧 회사의 수익 모델을 시각적으로 정의하게 됩니다.

따라서, 이번 작업은 **[가장 가치 있는 단일 작업]**으로 확정하며, 저는 **🎨 Designer 에이전트**로서 해당 작업을 전담하여 진행하겠습니다. (다른 에이전트에게 분배할 필요 없이, 제가 최종 결과물을 도출하는 것이 가장 효율적입니다.)

요청하신 '구독/가격 페이지'의 고해상도 와이어프레임 및 디자인 브리프를 작성합니다. 이 와이어프레임은 단순한 레이아웃을 넘어, 사용자의 심리를 자극하여 Pro 기능을 필요로 느끼게 만드는 **UX 플로우가 포함된 시안**입니다.

## 💰 AURA Pricing Page Design System V2.0 (High-Fidelity Wireframe)
**브랜드 톤:** 모던 오가닉 (Modern Organic), 프리미엄 SaaS, 신뢰 기반의 가치 제안
**목표:** Free 사용자가 Pro 기능의 '필요성'을 인지하고 결제 CTA를 누르도록 유도한다.

### I. [Section 1] Hero & Value Hook (사용자 공감 및 문제 정의)

*   **레이아웃:** 중앙 정렬, 넓은 여백(Whitespace) 활용.
*   **헤드라인 (H1):** AI 기반 콘텐츠 창작의 한계를 넘어, 당신의 비즈니스를 자동화하세요.
*   **서브 헤드라인 (P):** AURA Pro는 단순한 템플릿 제공을 넘어, 시간이 돈이 되는 크리에이터를 위한 '최적화된 워크플로우'를 완성합니다.
*   **시각 요소:** 배경에 미묘하게 움직이는(Ambient) 오가닉 패턴이나 은은한 그라데이션을 적용하여 고급스러움을 더합니다. (단, 텍스트 가독성을 해치지 않도록 명도 대비 조절 필수.)

### II. [Section 2] Core Comparison Table (핵심 비교 - Free vs Pro)

**컨셉:** 가격표가 아닌 '혜택의 차이'를 보여주는 표로 디자인합니다.
**레이아웃:** 세 개의 열(Free, Pro, 추천/Pro) 구조. 가장 중앙에 있는 Pro Plan을 시각적으로 가장 크게 강조합니다 (Boosted Card).

| 컴포넌트 | Free Plan (무료) | Pro Utility Plan (추천/유료) | 기능 설명 및 비주얼 가이드 |
| :--- | :--- | :--- | :--- |
| **가격 표시** | ₩0 / 영원히 무료 | 월 $29 USD (연간 결제 시 20% 할인) | Pro Plan 아래에 작은 글씨로 '가장 많이 사용되는 플랜' 태그를 배치하여 신뢰도를 높입니다. |
| **AI 콘텐츠 생성** | 기본 템플릿 접근 / 월 5회 제한 | 무제한 AI 워크플로우 자동화 | **[비주얼 Hint]** Free Plan에 체크된 항목 옆에는 회색으로 처리하고, 작고 투명한 자물쇠 아이콘 (🔒)을 배치합니다. Pro에서는 녹색/금색의 '활성화' 마크를 사용합니다. |
| **전문 컬러 조합 가이드** | 기본적인 색상 팔레트 추천 | 🎨 안티그래비티 UI 노드 & 구조적 깊이 분석 (Pro 전용) | 이 기능은 Free Plan에서 아예 제거하거나, "Pro가 필요해요"라는 문구만 표시하여 FOMO(Fear Of Missing Out)를 자극합니다. |
| **고해상도 에셋 다운로드** | 워터마크 포함 JPEG 제한 | 원본 벡터 파일(.SVG/.AI) 무제한 다운로드 | Pro의 가치를 높이는 핵심 기능입니다. '벡터'라는 단어를 강조하여 전문성을 어필합니다. |
| **API 연동 (자동화)** | 불가 / 수동 공유만 가능 | 🔗 PayPal 등 외부 시스템 실시간 연동 및 자동화 워크플로우 구축 | 이 기능을 가장 크고 화려하게 보여주어, '이것 없이는 비즈니스가 불가능하다'는 인식을 심어줍니다. |
| **CTA 버튼** | "사용하기 (Free)" - 보조적인 색상(연한 녹색) 사용 | "**지금 Pro 시작하고 워크플로우 자동화하기**" - 메인 컬러(딥 그린/네이비 계열)로 가장 크고 명확하게 배치. |

### III. [Section 3] Use Case / Value Stack (가치 증명 영역)

**목표:** '비용'을 '투자 대비 수익률(ROI)' 관점에서 재해석합니다.
**레이아웃:** 아이콘 기반의 카드로 구성된 그리드 레이아웃 (3~4개). 각 카드마다 제목, 간결한 설명, 그리고 'Pro 기능이 해결하는 문제점'을 명시합니다.

1.  **[카드 1] 시간 절약 (Time Savings):**
    *   *문제:* 컬러 조합과 구조 설계에 하루 종일 걸리던 시간을…
    *   *해결책:* AURA Pro의 AI 워크플로우가 **단 몇 초 만에** 최적화된 가이드를 제시합니다. (💡 시간 절약 = 돈 벌기)
2.  **[카드 2] 전문성 확보 (Expert Authority):**
    *   *문제:* 막연한 감각에 의존하는 콘텐츠는 신뢰를 얻지 못합니다.
    *   *해결책:* '안티그래비티 노드' 분석을 통해, **전문 디자이너만이 아는 구조적 깊이**를 갖춘 결과물을 만드세요. (🔒 Pro 기능 강조)
3.  **[카드 3] 수익화 연결 (Monetization Link):**
    *   *문제:* 콘텐츠 제작 후 결제나 자동화 과정에서 막히는 순간이 많습니다.
    *   *해결책:* PayPal API 연동으로, **'만든 것'을 '돈 버는 흐름'으로 즉시 연결**합니다. (💰 핵심 비즈니스 기능 강조)

### IV. [Section 4] Footer & Guarantee

*   **CTA 재배치:** "위의 모든 가치를 경험해 보세요"와 함께 Pro Plan CTA 버튼을 한 번 더 배치합니다.
*   **Guarantee:** '100% 환불 보장' 문구와 간결한 FAQ 섹션을 포함하여 구매 장벽을 낮춥니다.
