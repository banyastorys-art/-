## I. Hero Section — Value Hook & Headline Set (3안)

### 🎯 안 1: "비즈니스 자동화" 중심 (직관적 가치)
```markdown
# H1: 당신의 시간을 AI 가 대신할 때, 수익은 자동으로 배가됩니다.
# H2: 단순 템플릿 제공을 넘어, 실제로 돈이 되는 워크플로우를 완성하세요.

[CTA 버튼] → 무료 플랜 시작 / Pro 기능 체험하기
```

### 🎯 안 2: "결과물 중심" (보상 강조)
```markdown
# H1: 전문가 수준의 콘텐츠 제작은 이제 당신도 가능합니다.
# H2: 1 인 기업이라도, 10 명 팀의 결과물을 하루에 만들어보세요.

[CTA 버튼] → 지금 Pro 로 업그레이드하기 / 무료 플랜 확인
```

### 🎯 안 3: "심리적 후크" (무료→유료 전환 유도)
```markdown
# H1: 대부분의 크리에이터가 아까워하는 기능 — 바로 이 기능을 놓치면 손해입니다.
# H2: AURA Pro 는 월 $29 로, 당신의 콘텐츠 제작 시간을 10 배나 단축시켜줍니다.

[CTA 버튼] → 무료 플랜 → Pro 로 업그레이드 / Pro 기능 미리보기
```

## III. Psychological Hooks — 무료 플랜 사용자의 결제 망설임 해소

### 🧠 Hook 1: "손실 회피" (Loss Aversion)
```markdown
[문구]: "무료 플랜을 계속 사용하면, 월 $29 로 시간을 10 배 단축할 기회를 놓칩니다."
[설명]: 사람들은已获得한 것을 잃는 것에 더 민감하게 반응합니다. 무료 플랜 사용자에게 Pro 를 사용하지 않는 '비용' (시간 손실) 을 암시합니다.
```

### 🧠 Hook 2: "사회적 증명" (Social Proof)
```markdown
[문구]: "1,500+ 명의 크리에이터가 선택한 AURA Pro — 'Pro 로 전환 후, 콘텐츠 제작 시간이 80% 단축되었습니다.'"
[설명]: 다른 사람들이 성공을 얻었음을 강조하여, Pro 가 '올바른 선택'임을 암시합니다.
```

### 🧠 Hook 3: "가치 대비 가격" (Value-Price Ratio)
```markdown
[문구]: "월 $29 는 커피 한 잔의 비용에 불과하지만, 당신의 수익은 10 배 이상 증가할 수 있습니다."
[설명]: 가격을 '소박한 비용'으로 프레임하여, 실제 가치를 강조합니다.
```

### 🧠 Hook 4: "무료 플랜 → Pro 전환" (Easy Transition)
```markdown
[문구]: "무료 플랜 사용 중이시라면, 언제든 Pro 로 업그레이드하세요 — 데이터와 설정은 모두 유지됩니다."
[설명]: 무료→유료 전환의 장벽을 낮춰서, 결제 망설임을 해소합니다.
```

## VI. Copywriting Tone & Style Guidelines

### ✅ Must Do
- **결과 중심**: 기능 설명이 아닌, 그 기능이 사용자에게 주는 '혜택/결과'를 강조합니다.
- **긍정적 언어**: 부정적인 표현은 피하고, 긍정적인 프레임으로 재구성합니다. (예: "제한됨" → "초기 버전", "비쌈" → "투자")
- **명확한 CTA**: 각 섹션마다 구체적인 행동 지시를 포함합니다.

### ❌ Don't Do
- **기술 용어 남용**: 사용자가 이해하기 어려운 전문 용어는 피합니다.
- **부정적 언어**: "못 함", "제한됨", "비쌈" 같은 표현은 사용합니다.
- **모호한 CTA**: "더 알아보기"보다, 구체적인 행동 지시를 포함합니다.
